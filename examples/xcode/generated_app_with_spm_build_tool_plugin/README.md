# Application with an SPM build tool plugin

This example contains a project that depends on a local SPM module (`LocalSwiftPackage`) whose target
applies a build tool plugin through SwiftPM's `plugins:` argument:

```swift
.target(
    name: "LocalSwiftPackage",
    plugins: [
        .plugin(name: "SwiftLint", package: "SwiftLintPlugin"),
    ]
)
```

It exists to ensure that Xcode compiles and runs build tool plugins declared this way in projects
generated by Tuist.
